# Wowza Streaming Server

This document describes common Wowza Streaming Engine URL formats for accessing media content, including MP4 VOD streams, HLS playlists, and SMIL-based adaptive bitrate (ABR) streams.

This guide also references tools for:

- Configuring a Wowza server.
- Generating SMIL files for adaptive bitrate streaming.
- Testing HLS playback URLs.

---

# Overview

Wowza Streaming Engine commonly uses port `1935` for streaming protocols.

Media URLs generally follow this format:

```
http://<wowza-host>:1935/<application>/_definst_/<stream-path>/playlist.m3u8
```

For HLS playback, the URL typically ends with:

```
playlist.m3u8
```

Example:

```
http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8
```

---

# Network Access Requirements

The Wowza server URLs documented here are intended for use within the internal network environment.

Before testing any stream URLs, connect to the organization's VPN:

1. Establish a VPNSEC connection.
2. Verify that the Wowza hostname is reachable.
3. Test the HLS URL using a compatible player or command-line tool.

Example:

```bash
curl -I \
"http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8"
```

If the VPN connection is not active, the Wowza server may not be reachable and URL tests may fail.

Common symptoms of missing VPN access:

- DNS lookup failures for the Wowza hostname.
- Connection timeouts on port `1935`.
- HTTP connection errors when requesting `playlist.m3u8`.
- Playback failures in VLC, ffplay, or browser-based players.

# HLS Streaming URLs

## Single MP4 File

A single MP4 file can be streamed using Wowza's VOD application.

### URL Format

```
http://<wowza-host>:1935/<application>/_definst_/mp4:<path>/<file>.mp4/playlist.m3u8
```

### Example

```
http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8
http://<wowza-host>:1935/vod/_definst_/mp4:tamwag/rosie/9_JANE_TUCKER_REEL_3_3200k.mp4/playlist.m3u8
```

Components:

| Component | Description |
|---|---|
| `<wowza-host>` | Hostname or IP address of the Wowza server |
| `1935` | Default Wowza streaming port |
| `vod` | Wowza VOD application name |
| `_definst_` | Default Wowza stream instance |
| `mp4:sample.mp4` | MP4 media file |
| `playlist.m3u8` | HLS playlist generated by Wowza |

# SMIL-Based Adaptive Bitrate (ABR) Streaming

Wowza supports adaptive bitrate streaming using SMIL files.

A SMIL file describes multiple versions of a video, such as:

- Different resolutions
- Different bitrates
- Different codecs

A SMIL file can be created manually or generated automatically using tools such as `gen_abr_smil.py`.

Wowza dynamically generates an HLS master playlist from the SMIL definition.

## URL Format

```
http://<wowza-host>:1935/<application>/_definst_/smil:<path>/<file>.smil/playlist.m3u8
```

## Example

```
http://<wowza-host>:1935/vod/_definst_/smil:tamwag/rosie/9_JANE_TUCKER_REEL_3.smil/playlist.m3u8
```

Components:

| Component | Description |
|---|---|
| `<wowza-host>` | Hostname or IP address of the Wowza server |
| `1935` | Default Wowza streaming port |
| `vod` | Wowza VOD application |
| `_definst_` | Default Wowza stream instance |
| `smil:` | Indicates a SMIL-based stream |
| `tamwag/rosie/9_JANE_TUCKER_REEL_3.smil` | SMIL file path |
| `playlist.m3u8` | Generated HLS playlist |

# SMIL URL vs Direct MP4 URL

Wowza can serve content either directly from an MP4 file or through a SMIL file.

The correct URL depends on whether adaptive bitrate streaming (ABR) is required.

## Direct MP4 URL

A direct MP4 URL points to a single media file.

Example:

```
http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8
```

Characteristics:

- Serves a single video rendition.
- No bitrate switching is available.
- The client receives only the bitrate and resolution encoded in the MP4 file.
- Simpler to configure and maintain.

Use a direct MP4 URL when:

- There is only one available video quality.
- The source file is already optimized for the expected playback environment.
- Bandwidth adaptation is not required.

---

## SMIL ABR URL

A SMIL URL points to a SMIL file that defines multiple video renditions.

Example:

```
http://<wowza-host>:1935/vod/_definst_/smil:tamwag/rosie/9_JANE_TUCKER_REEL_3.smil/playlist.m3u8
```

Characteristics:

- Provides adaptive bitrate streaming.
- Contains multiple video qualities.
- Wowza generates an HLS master playlist dynamically.
- The player automatically selects the best rendition based on network conditions.

Use a SMIL URL when:

- Multiple resolutions or bitrates are available.
- Playback should adapt to changing network conditions.
- The same content needs to support many devices.

---

## Comparison

| Feature | Direct MP4 URL | SMIL ABR URL |
|---|---|---|
| Single bitrate | Yes | No |
| Multiple resolutions | No | Yes |
| Adaptive bitrate switching | No | Yes |
| Requires SMIL file | No | Yes |
| Generated HLS master playlist | No | Yes |
| Simpler configuration | Yes | No |
| Better for variable networks | No | Yes |

# SMIL File Structure

A typical SMIL file defines multiple renditions of the same video.

Example:

```xml
<?xml version='1.0' encoding='UTF-8'?>
<smil title="">
  <body>
    <switch>
      <video src="9_JANE_TUCKER_REEL_3_300k.mp4" width="448" height="252" systemLanguage="eng">
        <param name="videoBitrate" value="240071" valuetype="data"/>
        <param name="audioBitrate" value="96015" valuetype="data"/>
      </video>
      <video src="9_JANE_TUCKER_REEL_3_800k.mp4" width="640" height="360" systemLanguage="eng">
        <param name="videoBitrate" value="684031" valuetype="data"/>
        <param name="audioBitrate" value="96015" valuetype="data"/>
      </video>
      <video src="9_JANE_TUCKER_REEL_3_3200k.mp4" width="1280" height="720" systemLanguage="eng">
        <param name="videoBitrate" value="2877275" valuetype="data"/>
        <param name="audioBitrate" value="96015" valuetype="data"/>
      </video>
    </switch>
  </body>
</smil>
```

Wowza uses this information to create an HLS master playlist containing the available bitrate variants.

# Generating SMIL Files

For workflows involving multiple video renditions, SMIL files can be generated automatically.

The `gen_abr_smil.py` script creates Wowza-compatible SMIL files for adaptive bitrate streaming.

Script:

https://github.com/rrasch/server-scripts/blob/master/gen_abr_smil.py

Documentation:

https://github.com/rrasch/server-scripts/blob/master/SMIL_Generation.md

## Purpose

`gen_abr_smil.py` automates the creation of SMIL files by:

- Scanning available media renditions.
- Extracting video metadata.
- Generating the required SMIL XML structure.
- Creating a Wowza-compatible ABR playlist definition.

The generated SMIL file can then be accessed using a Wowza SMIL HLS URL:

```
http://<wowza-host>:1935/vod/_definst_/smil:<path>/<file>.smil/playlist.m3u8
```

## Example Workflow

1. Encode multiple versions:

```
9_JANE_TUCKER_REEL_3_300k.mp4
9_JANE_TUCKER_REEL_3_800k.mp4
9_JANE_TUCKER_REEL_3_3200k.mp4
```

2. Generate the SMIL file:

```bash
./gen_abr_smil.py 9_JANE_TUCKER_REEL_3
```

3. Place the generated SMIL file where Wowza can access it.

4. Request the HLS playlist:

```
http://<wowza-host>:1935/vod/_definst_/smil:9_JANE_TUCKER_REEL_3.smil/playlist.m3u8
```

# Wowza Server Administration

Setting up a Wowza Streaming Engine server involves configuring the server environment and preparing it for media playback and ABR workflows.

For automated server setup, the `wowza_post_install.py` script can be used after installing Wowza.

Script:

https://github.com/rrasch/server-scripts/blob/master/wowza_post_install.py

Documentation:

https://github.com/rrasch/server-scripts/blob/master/Wowza_Install.md

## Purpose

`wowza_post_install.py` automates common Wowza server configuration tasks.

Typical tasks include:

- Installing required system dependencies.
- Configuring the Wowza environment.
- Setting up application directories.
- Applying server configuration changes.
- Preparing the server for VOD and HLS streaming workflows.

## Installation Workflow

1. Install the operating system and required packages.

2. Install Wowza Streaming Engine.

3. Run the post-installation configuration script:

```bash
./wowza_post_install.py
```

4. Verify the Wowza application configuration.

5. Test playback:

```
http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8
```

6. Configure media storage and generate SMIL files for ABR playback.

# Chrome Extension Player URLs

Some browser-based players wrap the actual media URL inside a Chrome extension URL.

Example:

```
chrome-extension://<extension-id>/player.html#<encoded-url>
```

The URL after the `#` is URL encoded.

Example:

```
chrome-extension://emnphkkblegpebimobpbekeedfgemhof/player.html#http%3A%2F%2F<wowza-host>%3A1935%2Fvod%2F_definst_%2Fmp4%3Asample.mp4%2Fplaylist.m3u8
```

The embedded URL is:

```
http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8
```

Decode with:

```bash
python3 -c "import urllib.parse; print(urllib.parse.unquote('<encoded-url>'))"
```

```bash
curl -I \
"http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8"
```

## View Playlist Contents

```bash
curl \
"http://<wowza-host>:1935/vod/_definst_/mp4:sample.mp4/playlist.m3u8"
```

A SMIL-based stream should return a master playlist containing multiple variant streams.

---

# Notes

- Port `1935` is the default Wowza streaming port.
- `_definst_` refers to Wowza's default application instance.
- `playlist.m3u8` is generated dynamically by Wowza; it is usually not a file stored on disk.
- SMIL files are commonly used for adaptive bitrate streaming.
- `gen_abr_smil.py` generates SMIL definitions used by Wowza ABR workflows.
- `wowza_post_install.py` prepares the server environment for Wowza streaming workflows.
- The same media can often be accessed using different protocols depending on the Wowza configuration (HLS, RTMP, MPEG-DASH, etc.).
